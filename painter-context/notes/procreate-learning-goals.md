# Procreate 课程技能点预期与目标

## 结论（一句话）

这门 Procreate 选修软件课按「基础快速略看 → 工具重点吃透 → 落地 Q 版头像」推进，学完要能独立走完 Q 版头像的草图到上色全流程。

## 要点

- 快速略看的基础内容：画布、图层、选区、快捷手势。
- 重点注意：
  - 笔刷 1 & 2 的导入；
  - 涂抹工具在突出插画效果上的用法；
  - 滤镜功能如何增加氛围；
  - 辅助绘画的妙用；
  - 画笔进阶如何更好掌握。
- 课程重点：Q 版草图的绘制与上色。

## 例子 / 我的踩坑

- 学习目标（验收标准）：在小红书找一只喜欢的 Q 版头像，从绘制草图到上色完整临一遍，最后把它作为 GitHub 头像与小红书头像（来源：用户口述，2026-09-29）。
