# 二次元插画学习手册

## 用户原文

~~~~~~~~~~~~~~~~~~~~~~~~~~~~
我在上这个的第一个段，二次元插画学习手册，学到了二次元插画的学习顺序，为：
1. 线稿阶段：细分为线基础、空间基础、头像线稿、人体线稿、衣服线稿；
2. 铺色和二分阶段：光影和二分概括，色彩的基础运用；
3. 细化阶段：主题立绘创作和主题插画创作。

学到了学习的坏习惯和有效的学习方式：
1. 坏习惯：拖延症；盲目练习；与当前基础不匹配（这个我就先学A阶段简单的，有余力再调整B阶段，如果这个课程我全套跟下来，全部做了A的，我已经十分了不起了！！！）；学习注意力不集中（注意看课程总结和课后章节，边看边记笔记到这里harness）
2. 画师的心态和习惯养成：
1). 害怕出错和画的出错是不一样的，二次元的线稿多，很细腻，别反复纠结，大胆画，可以多尝试几次，老师就能提意见和纠正。
2). 方向目标和积累的关系：边学习边积累喜好的插画，创作阶段就可以学习和创作。
3). 生活与灵感的来源：生活、动漫、游戏、漫展了解二次元文化。
总结：系统的稳健的提高和好的绘画心态两者缺一不可。
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

## AI 整理与补充

来源：老师讲解后的用户整理总结

当前采用的结论：二次元插画学习按“线稿阶段 → 铺色和二分阶段 → 细化阶段”推进；学习过程中要让训练内容与当前基础匹配，避免拖延、盲目练习和注意力分散，同时保留大胆尝试、积累偏好素材和从生活中获取灵感的习惯。系统的稳健提高与良好绘画心态需要并行培养。

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~
我在上这个的第二段，是课程总结：
1. 我们学习的是赛璐璐画法的二次元插画，特点是线稿清晰明显，且扁平，与厚涂和半厚涂靠光影油画堆叠不同，二次元的线稿清晰，入手容易，且是动漫的核心；
2. 插画的背后是系统性训练，一个目标达成背后是多个小目标支撑；
3. 要循序渐进地学习，一个阶梯一个阶梯闯关式地学习，戒骄戒躁；
4. 作业按时提交，多提交多发现问题多解决问题；
5. 多接触插画作品和二次元相关事务，提高鉴赏能力和创作能力。

绘画心得分享：
1. 前期枯燥练习怎么度过？线造型和空间造型都是，多趁热打铁，把这两个打基础做牢，要多花时间；
2. 绘画中的瓶颈期？知识多跟会画是两回事，这样反而画的很难受，解决就是从头到尾理清，从简单开始练手感；
3. 前期画不动，心有余而力不足？适当调整一些绘画素材；一开始精力会一大部分花在工具上，是很正常的，跟工具建立联系；
4. 某一样问题长期不能解决？对复杂的问题进行拆分，例如不会画人体，那就先练比例，或者局部练习。跟我画静物最后型不准一样，应该拆分的细化问题是：外框的比例拿捏；切型的拿捏，物品结构的刻画，物品相对位置的负型，线条的轻重，画面重点，画面的灵动等。
5. 因能力不足产生的自我怀疑？更多的练习，一定要有一个过程，所以要更多的耐心去度过这个过程。

## AI 整理与补充

来源：2026-10-19 课程总结，第 2 段用户原文
记录日期：2026-10-19

当前采用的结论：赛璐璐画法的二次元插画以清晰、明显、扁平的线稿为重要特征，线稿也是动漫插画的核心入口。学习应采用阶梯式训练，把系统目标拆成可操作的小目标；遇到人体、静物等复杂问题时，继续拆分为比例、结构、相对位置、线条轻重和画面重点等具体问题。前期应允许自己适应工具、调整素材并通过持续练习积累手感，以耐心度过瓶颈和能力不足带来的自我怀疑；同时多接触插画作品与二次元相关内容，提升鉴赏和创作能力。
