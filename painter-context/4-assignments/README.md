# 4-assignments/

这里按主课程 ID 存放“有硬截止”的作业记录，真正的交付任务与 DDL 都写在这里。

- 路径：`4-assignments/<course-id>/as-NNN-<slug>.md`
- frontmatter 的必填事实字段：`id`、`title`、`due`、`status`、`course`
- `course` 必须引用已有课程，且与所在子目录一致
- 真实 DDL 只在 `due` 中记录；课程大纲、平台页面、聊天里的截止日期都只是参考
- 若任务变更，正文中写明日期调整记录：`- YYYY-MM-DD 调整为 X，原因：…`

原则：

- `4-assignments/<course-id>/` 是该课程的硬截止事实源
- 计划日期、排期日期属于软安排，不等于正式 DDL
