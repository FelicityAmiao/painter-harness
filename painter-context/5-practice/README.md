# 5-practice/

这里按主课程 ID 存放每次练习记录，记录的是“做了什么、为何做、结果如何、下一步怎么改”。

- 路径：`5-practice/<course-id>/YYYY-MM-DD-<slug>.md`
- 必填字段：`id`、`date`、`goal`、`result`、`course`
- `course` 必须引用已有课程，且与所在子目录一致
- `goal` 必须写清本次练习的目的，不是流水账记录
- 练习结果可用 `ok` / `partial` / `missed`，并在正文补充反思

原则：

- 练习记录是事实，不是计划
- 练习目标与结果要能支撑里程碑 checklist 和技能树评估
- `5-practice/<course-id>/` 不是“待办清单”，而是已发生的训练证据
