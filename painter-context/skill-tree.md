# 技能树 skill-tree

插画 / 游戏美术的技能定义。**级别是唯一需要人工（AI 周复盘）维护的列**，练习次数与最近练习由 `npm run rollup` 自动统计。

## 评定标准（L0–L5）

| 级别 | 含义 | 判定参考 |
| --- | --- | --- |
| L0 | 未接触 | 无相关练习记录 |
| L1 | 入门 | 理解概念，做过 ≥1 次针对性练习 |
| L2 | 初步掌握 | ≥3 次练习且最近一次 `result: ok`，能完成临摹/规定练习 |
| L3 | 熟练 | 能默写、举一反三（结合练习反思判断，不看次数） |
| L4 | 应用 | 能在完整作品中独立稳定地用上该环节 |
| L5 | 输出 | 稳定达到商用地步，可给别人讲明白 |

升降级规则：脚本只给 L1/L2 的**次数型候选建议**；L3 及以上必须由 AI 读练习反思后判断，每次升降附一句依据，用户确认后改表。
