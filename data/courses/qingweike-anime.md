# 轻微课 · 二次元插画（9 个月）

- 形式：在线课程 + 阶段作业（有平台 DDL，作业 DDL 写入 `data/assignments/`）
- 工具：板绘 + PS
- 关联技能：`illustration/*`、`foundation/*`

## 课程风格参考

风格介绍图展示了课程相关的常见插画方向，作为风格认知参考，不代表每种风格都是独立教学阶段：

| 风格 | 画面特点 |
| --- | --- |
| 二次元插画 | 简洁线条、明快色彩、独特构图，以角色、场景和物体塑造二次元世界 |
| 动漫厚涂 | 浓郁色彩、丰富层次、明确光影与材质表现 |
| 角色原画 | 面向动画、漫画、游戏的角色、场景与道具前期设计 |
| iPad 商业插画 | 色彩浓郁、笔触鲜明，强调图形概括和视觉设计 |
| 古风插画 | 融合传统文化意象、诗词意境、细腻线条与古典配色 |
| 漫画创作 | 结合图像、对白和分镜，通过画面顺序讲述故事 |

来源：`assets/course-anime.png`。

## 课程大纲

课程周期：270 天，分为基础阶段 106 天、提高阶段 74 天、创作阶段 90 天；另含预科软件课。具体起止日期与平台作业 DDL 待补录。

### 预科阶段（赠送）

- PS 绘画基础教程、SAI 绘画教程、Procreate 绘画教程、学前软件课。

### 基础阶段（106 天）

| 模块 | 时长 | 内容 |
| --- | --- | --- |
| 线造型基础 | 10 天 | 二次元插画学习手册；画笔基本功能与运笔；线条随笔训练；不同造型的运线技巧；线条层次与轮廓概括；造型观察与绘制流程；图形概括、联想思维；模块总结 |
| 空间造型基础 | 18 天 | 初识透视；透视意识训练；透视结构切割与概括；简单形体转角规律；型体承载与遮挡；常见及复杂物体概括；场景基础框架；模块总结 |
| 头像基础训练 | 18 天 | 识别日系插画头像；头部向度与透视；眼睛画法与类别；头部角度变化与五官整合；基础人物表情概括；头颈关系与动态分析；发型基础认识与画法；发饰添加与运用；头像造型分析与创作；模块总结 |
| 第一项复习周 | 7 天 | 阶段复习与练习 |
| 人体造型基础 | 24 天 | 标准化人体建立与比例测量；骨骼认识与体块理解；局部体块、肌肉与关节分析；全身体块与角度训练；动态简化；人物与手脚表达；人体练习与动态概括；模块总结 |
| 第三项复习周 | 7 天 | 阶段复习与练习 |
| 人物服装穿搭 | 15 天 | 道具穿搭与变形处理；褶皱原理与概括分析；布料材质与服装裁剪；常见服装结构；现实题材服装装饰简化；人物服饰搭配；模块总结 |
| 第三项复习周 | 7 天 | 阶段复习与练习 |
| 基础篇：插画初体验 | 未标注 | 插画基础作品练习与阶段综合应用 |

### 提高阶段（74 天）

| 模块 | 时长 | 内容 |
| --- | --- | --- |
| 光影与二分概括 | 7 天 | 光影认识；光源角度与暗部计算；形体起伏与光影变化；日系二分应用；光影与二分概括总结 |
| 色彩的基础运用 | 60 天 | 色彩基本原理与取色；日光及关系色彩训练；色稿概括与变调；头像创作与色彩融合；材质通用性分析；局部上色与头发、眼睛、皮肤质感；头像色彩细化；立绘创作；色彩基础运用总结 |
| 第四项复习周 | 7 天 | 阶段复习与练习 |
| 提高篇：技艺进阶展示 | 未标注 | 展示提高阶段作品与综合运用 |

### 创作阶段（90 天）

| 模块 | 时长 | 内容 |
| --- | --- | --- |
| 主题立绘创作 | 45 天 | 商业立绘介绍；设计稿应用；项目及文案分析；立绘人体动态；线稿阶段；上色阶段与画布角色；二分调整与过渡；立绘光影调整；收到型与画面调整；作品包装与三视图 |
| 主题动漫插画创作 | 45 天 | 主题插画设计思路；商业常用构图；主题插画草图；色彩应用拓展；色彩氛围图应用；插画草图调整；吸塑型画与调整 |
| 创作篇：创作成果分享 | 未标注 | 阶段作品展示与成果分享 |
